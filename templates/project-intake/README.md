# Project Intake Pack

Copy these six files into `projects/<project-id>/intake/` and complete them in order.
The human sponsor approves scope after document 01, the affected user validates the current
state after document 02, and the decision owner approves Ready after documents 03–04.
Document 05 records checker, UAT, release, rollback, and outcome evidence.

Do not delete unknown fields. Mark them `UNKNOWN`, assign an owner and trigger, and stop at the
relevant gate. The canonical process is `docs/PROJECT-INTAKE-AND-PRODUCTION-LOOP.md`.
