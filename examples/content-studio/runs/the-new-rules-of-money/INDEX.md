# 📂 Series Run — The New Rules of Money (@TheNewRules101)

Full series for the channel, in **dedicated** voice. **Topic:** money, psychology-first, contrarian.
**Format:** 4–6 min faceless essays · **Device:** each episode retires an *Old Rule*, installs a
*New Rule* · **Run date:** 2026-07-11.

```
├── 02-scripts-fulllength-archive/ ← original full-length versions (backup)
├── 03-thumbnails/         ← purple/cream thumbnail briefs (all 15)
├── 04-growth/             ← growth plan tuned to launch stage (~10 subs)
├── 05-shorts/             ← Shorts cut plan (2–3 per episode)
├── 06-channel-fixes/      ← rewrites for your 3 existing video titles

```

**Script length options:** `02-scripts/` = ~5 min (recommended) · `02-scripts-4min/` = strict ~4 min ·
`02-scripts-fulllength-archive/` = original longer cut. Pick per video.
Glob in order: `find 02-scripts -name 'ep*.md' | sort`.
