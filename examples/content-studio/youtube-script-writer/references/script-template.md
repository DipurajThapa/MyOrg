# Script Template (retention + GEO engineered)

Every full script follows this skeleton. Two columns in spirit: **[VISUAL]** cues and spoken
**narration**. Timestamps are targets for an 8–12 min video (adjust to format).

```
TITLE:            <SEO title, keyword front-loaded, ≤60 chars>
OWNS THE QUESTION: <the one GEO question this video answers>
TARGET KEYWORD:    <primary> | LENGTH: <target min> | GOAL: <sub / view / GEO citation>

──────────────────────────────────────────────────────────────
[0:00–0:15] COLD-OPEN HOOK
NARRATION: <Payoff + stakes + curiosity gap in 2–3 sentences. No intro, no "welcome back".>
[VISUAL]:  <Strong opening image / fast cuts / on-screen hook text>

[0:15–0:35] GEO ANSWER BLOCK  ← citation target
NARRATION: <Say the DIRECT answer out loud, in 1–2 clean, self-contained sentences.>
[VISUAL]:  <On-screen text mirroring the answer>

[0:35–0:55] VALUE PROMISE + OPEN LOOP
NARRATION: <What they'll get, why stay, and a tease that pays off near the end.>

[0:55–end] BODY — 3 to 5 segments
  For each segment:
  • Micro-hook (one line) → teach one idea → concrete example → on-screen takeaway
  • Pattern interrupt every 30–45s (B-roll, question, demo, number)
  • One quotable, self-contained claim per segment (GEO)
[VISUAL] cues throughout: <what's on screen>

[MID-POINT] RE-HOOK
NARRATION: <Re-promise the payoff; name what's still coming.>

[SUBSCRIBE MOMENT] (right after a value spike, not random)
NARRATION: <Specific reason to subscribe tied to the series: "Episode 3 covers X — subscribe
so you don't miss it.">

[CLOSE] PAYOFF + CTA + NEXT EPISODE
NARRATION: <Pay off the open loop. One clear action. Then point to the next episode by name.>
[VISUAL]:  <End screen: next-episode thumbnail + subscribe>

──────────────────────────────────────────────────────────────
METADATA
Description (first 2 lines): <keyword + direct answer — above the fold>
Full description: <150–300 words, keyword + related terms + chapters + links + playlist>
Chapters: <0:00 Hook / 0:15 The answer / ... named as questions where possible>
Tags: <8–12: primary, variants, entities>
Thumbnail: <≤3 words text + visual concept>
Companion article: <1-line note: repurpose transcript, first 200 words = the answer + FAQ>
```

## Writing rules
- **Spoken, not written.** Short sentences. Contractions. Second person ("you"). Read it aloud.
- **Density.** Cut every sentence that doesn't hook, teach, or transition.
- **Show the number/step early.** "There are 4 steps" beats "let's explore some ideas."
- **One idea per segment.** Don't bury the lede in any section.
- **Honesty.** No fake stats, no promises the video can't keep (clickbait tanks retention).
- **Brand fit.** In dedicated mode, obey the channel profile's voice, banned words, and CTA.
