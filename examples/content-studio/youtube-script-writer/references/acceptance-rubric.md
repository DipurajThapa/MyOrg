# Acceptance Rubric (self-QA gate)

Score each dimension 0–2 (0 fail, 1 partial, 2 pass). **Ship only at ≥ 90% (23/26) with no
zeros.** Report the scores in the output.

| # | Dimension | Pass (2) means |
|---|---|---|
| 1 | Research grounded | Real sources cited; keywords + GEO questions come from live research, not guessed |
| 2 | No fabricated facts | Every stat has a source or is flagged unverified |
| 3 | Series is an arc | 15 episodes follow the 5-act structure; difficulty rises; binge loops present |
| 4 | One question per episode | No two episodes compete for the same query; no gaps |
| 5 | SEO titles | Keyword front-loaded, ≤60 chars, curiosity+clarity, all 15 present |
| 6 | Metadata complete | Description first-2-lines, chapters, 8–12 tags, thumbnail concept per episode |
| 7 | Hook quality | Every script's 0–15s states payoff+stakes, no slow intro |
| 8 | GEO answer block | Direct answer spoken in first 30s AND written in first 200 words |
| 9 | Retention engineering | Pattern interrupts, open loops, re-hook, subscribe moment present |
| 10 | Original element | ≥1 proprietary framework/number/named method (GEO citation bait) |
| 11 | Growth plan | Covers packaging, retention, binge, Shorts funnel, GEO distribution, analytics+benchmarks |
| 12 | Brand fit | In dedicated mode, obeys channel profile voice/format/banned words/CTA |
| 13 | Governance | Nothing published/scheduled; scripts + plan only; approval gate stated |

## Auto-fixes before shipping
- Title > 60 chars → tighten.
- Missing GEO question on any episode → assign one from the research question surface.
- Any unsourced stat → remove or replace with a sourced one.
- Retention gaps (no pattern interrupt for >60s) → insert one.
