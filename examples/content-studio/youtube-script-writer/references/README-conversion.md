# From General Tool → Your Channel's Dedicated Content Writer

The skill ships as a **general** YouTube writer so it works on any topic out of the box. To
convert it into *your channel's* dedicated writer — one that sounds like you, targets your
audience, and pushes your funnel — you fill one file. No code.

## The one-file switch
Edit **`config/channel-profile.md`**. Every field you fill replaces a general assumption with
your channel's reality. The skill checks this file on every run:
- **All `<UNSET>`** → *general mode* (broad best-practice writer; states its assumptions).
- **Filled** → *dedicated mode* (your voice, audience, format, CTA, banned words, proof).

## How each field changes the output
| Field | Changes |
|---|---|
| Niche / positioning | Topic angle, which sub-queries to own, competitive differentiation |
| Audience + "how they talk" | Keyword choice, GEO question phrasing, examples, objections handled |
| Tone / banned words / signature phrases | The literal voice of every script; intro/outro |
| Primary goal + CTA + funnel | Subscribe vs. lead-gen framing; where/how the CTA lands |
| Format / length / cadence | Script pacing, number of segments, Shorts cut points, publish plan |
| Proprietary frameworks / data | The GEO "original element" — your citation bait |
| Compliance notes | Auto-flags claims for review (e.g. financial/medical) |

## 3-step conversion
1. **Interview yourself (or let the skill interview you).** Ask Claude: *"Set up the YouTube
   writer for my channel"* — it walks you through the profile fields and writes them in.
2. **Add your proof.** Fill "proprietary frameworks / data / case studies" — this is what makes
   your videos citable by AI engines (GEO) and un-copyable by competitors.
3. **Run a calibration script.** Generate one episode, read it aloud, and correct the voice.
   Feed corrections back into the profile's "Voice & style" section. Two iterations locks it in.

## Keeping it sharp
- Re-run calibration whenever your positioning shifts.
- Store the profile in the company memory too, so other departments (CMO, brand-voice) stay
  consistent with the channel voice.
- Multiple channels? Keep one profile file per channel and tell the skill which to load.
